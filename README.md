# Peintres français — NVO987

## Présentation

**Peintres français** est une base de données publique et consultable consacrée aux personnes liées à la peinture française.

Le site est édité par **NVO987 — Culture Visuelle Moderne et Contemporaine**.

Site : https://peintres-fr.nvo987.eu/

Site de l'éditeur : https://www.nvo987.fr/

Contact : contact@nvo987.eu

## Objectif du projet

Le projet a pour objectif de proposer une ressource publique et exploitable par les humains comme par les machines concernant les peintres français.

Les données sont principalement issues de Wikidata.

Chaque fiche peut notamment contenir :

- le nom de la personne ;
- l'identifiant Wikidata ;
- un lien vers Wikipédia ;
- le site officiel de l'artiste lorsqu'il est disponible.

La recherche et le filtrage des données sont effectués directement dans le navigateur.

## Données

Le fichier principal utilisé par le site est :

https://peintres-fr.nvo987.eu/painters.json

La structure des données utilise notamment les champs suivants :

- name : nom de la personne ;
- wikidata : identifiant Wikidata ;
- wikipedia : URL de la page Wikipédia lorsqu'elle est disponible ;
- website : site officiel lorsqu'il est disponible.

Exemple de structure JSON :

{
  "painters": [
    {
      "name": "Nom de l'artiste",
      "wikidata": "Q123456",
      "wikipedia": "https://fr.wikipedia.org/wiki/Nom_de_l_artiste",
      "website": "https://example.com/"
    }
  ]
}

Certains champs peuvent être absents ou vides lorsqu'aucune information correspondante n'est disponible.

## Mise à jour

Le jeu de données est prévu pour être actualisé régulièrement, avec une fréquence indicative hebdomadaire.

Les informations peuvent évoluer en fonction des données disponibles dans Wikidata et des modifications apportées aux sources externes.

La présence d'une personne dans cette base ne constitue pas une certification officielle de son statut, de sa carrière ou de son activité artistique.
