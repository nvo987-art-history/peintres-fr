Base de données

Peintres
français

A Peintres français est une base de données publique et exploitable par machine consacrée aux entités personnelles liées à la peinture française. Son jeu de données repose sur des enregistrements provenant de Wikidata, réutilisables sous licence CC0 1.0 ; chaque enregistrement contient le nom de l’artiste, son identifiant Wikidata, un lien vers Wikipédia et, lorsqu’il est disponible, son site web officiel. La couche de publication web assure le chargement des enregistrements côté client, leur recherche par nom, leur filtrage et leur affichage dynamique. La mise à jour hebdomadaire du jeu de données permet l’intégration périodique des modifications apportées aux données sources. Le projet a pour finalité principale de maintenir un ensemble de données consultable et utilisable comme source de référence et de soutien à la recherche dans les domaines de l’histoire de l’art numérique et de la recherche sur le patrimoine culturel.

Répertoire

Peintres

Recherchez un peintre par son nom ou parcourez les enregistrements disponibles. Les résultats sont chargés dynamiquement depuis le fichier de données public.

01

Éditeur du site

Les informations administratives complémentaires de l’éditeur sont disponibles sur : www.nvo987.fr

02

Nature du service

Peintres français est une base de données en ligne consacrée aux personnes liées à la peinture française. Le service permet de rechercher et consulter les informations disponibles dans le jeu de données.

Une même personne peut apparaître dans plusieurs contextes lorsque les données sources l’associent à différentes activités ou catégories.

03

Non-affiliation

Ce site n’est affilié à aucune institution publique, aucun musée national, aucune collectivité territoriale et aucune plateforme officielle de la culture française.

Les noms, marques et dénominations cités restent la propriété de leurs détenteurs respectifs.

04

Données personnelles

Le site est conçu selon une approche de privacy by design.

  • Aucune inscription ou compte utilisateur
  • Aucun formulaire de collecte
  • Aucune base de données utilisateur
  • Aucun identifiant persistant volontairement créé

  • Aucune analyse d’audience volontaire

L’hébergement peut toutefois générer des journaux techniques nécessaires à la sécurité et au fonctionnement de l’infrastructure.

05

Le site est conçu pour rester consultable sans acceptation de cookies non essentiels.
