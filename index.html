Peintres français

Répertoire

Base de données publique consacrée aux peintres français. Les enregistrements proviennent de Wikidata et sont présentés sous une forme consultable, recherchable et exploitable. Chaque entrée peut contenir le nom de l’artiste, son identifiant Wikidata, un lien vers Wikipédia et, lorsqu’il est disponible, son site web officiel.

Chargement des peintres…

1. Éditeur du site

Le présent site web peintres-fr.nvo987.eu est édité et exploité par l’association NVO987 Culture Visuelle Moderne et Contemporaine.

Les mentions légales complètes et officielles concernant l’éditeur sont accessibles ici : www.nvo987.fr

2. Nature du service

Peintres français est une base de données en ligne consacrée aux artistes liés à la peinture française. Les données sont organisées afin de permettre la recherche et la consultation des personnes référencées. Lorsqu’elles sont disponibles, les fiches peuvent contenir un identifiant Wikidata, une page Wikipédia et un site web officiel.

Les données sont issues principalement de Wikidata et peuvent être mises à jour périodiquement afin d’intégrer les évolutions de la source.

3. Non-affiliation / absence de représentation

Ce site n’est affilié à aucune institution publique ou privée, aucun musée, établissement culturel, fondation ou plateforme officielle. Les noms, marques et dénominations cités restent la propriété de leurs détenteurs respectifs.

4. Données personnelles / RGPD

Le site est conçu selon une approche privacy by design.

  • Aucune inscription et aucun compte utilisateur
  • Aucun formulaire de collecte de données personnelles
  • Aucune base de données utilisateur
  • Aucun identifiant persistant
  • Aucun profilage ou ciblage publicitaire
  • Aucune analyse d’audience volontaire
  • Aucun pixel marketing

Aucune donnée personnelle n’est intentionnellement collectée, vendue, cédée ou conservée par l’éditeur dans le cadre de ce service.

Le site est hébergé via GitHub Pages. Comme tout service d’hébergement, l’infrastructure peut traiter certains journaux techniques nécessaires à la sécurité, à la disponibilité et au fonctionnement du service.

5. Cookies / tracking

Aucun cookie publicitaire, outil de mesure d’audience, traceur tiers ou outil d’analyse comportementale n’est volontairement intégré à ce site.

6. Exactitude / absence de garantie

Les informations proviennent d’une base Open Data collaborative, Wikidata. Elles peuvent être inexactes, obsolètes, incomplètes ou modifiées sans préavis. En cas de divergence, les sources institutionnelles ou officielles pertinentes font foi.
